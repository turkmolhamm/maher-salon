## 🚀 رفع التطبيق على الإنترنت (مجاناً في 5 دقائق)

### الخطوة 1 — GitHub
1. روح على https://github.com/new
2. اسم المشروع: `maher-salon`
3. اضغط "Create repository"
4. ارفع كل الملفات (drag & drop أو Git)

### الخطوة 2 — Vercel (استضافة مجانية)
1. روح على https://vercel.com → سجّل بحساب GitHub
2. اضغط "New Project"
3. اختر مشروع `maher-salon`
4. اضغط **Deploy** — خلاص! 🎉

### الخطوة 3 — دومين خاص (اختياري ~$10/سنة)
1. اشتري دومين من https://namecheap.com
   - مثال: `mahersalon.com` أو `mahersalon.jo`
2. في Vercel → Settings → Domains → أضف دومينك
3. اتبع التعليمات (تعديل DNS في Namecheap)
